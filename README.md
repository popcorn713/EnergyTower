# EnergyTower
能量塔科技是一个围绕「能量塔」与「能量链路扳手」的小型科技模组，核心玩法是无线能量传输：  - 能量塔（Energy Tower）：一个储能方块，内置高达 1000 万 FE 的缓存，接受任意标准 FE 设备 / 线缆 / 发电机的充电，然后通过「无线链路」向绑定的机器供电——不需要任何导线，也没有距离限制（同一维度内任意距离）。 - 能量链路扳手（Energy Link Wrench）：管理无线链路的配置工具，负责选定发射源、绑定 / 解绑目标机器、批量绑定、调节传输速率、切换传输模式等全部操作。  模组体积小、无额外前置，接入的是 Minecraft 生态通用的标准 FE 能量接口，因此可与绝大多数使用 FE 的科技模组（如 Mekanism 等）即插即用，直接对它们的机器无线供电。
